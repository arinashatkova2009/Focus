# Focus — готовая Windows-сборка и проект Qt

## Запуск

1. Полностью распакуйте архив в обычную папку (не запускайте из окна ZIP).
2. Откройте START_FOCUS_QT.bat или appfocus.exe рядом с ним.
3. Выберите «Войти» либо «Регистрация».

Qt и Python для готовой сборки отдельно устанавливать не нужно.
Демо-доступ: arina / 1234. Этот аккаунт и вымышленные начальные данные оставлены
для проверки интерфейса. Новая регистрация создаёт сотрудника без повышенных прав.

Чтобы изменить исходники, откройте CMakeLists.txt в Qt Creator с Desktop Qt 6.10+
(проверено на 6.12.0 MinGW). Нужны Quick, Quick Controls 2, Quick Dialogs 2,
Network, Multimedia, Shader Tools. Исходники и среда runtime/python входят в архив.

## Что объединено

Из Focus-no-registration.zip взяты папки и библиотека документов, безопасный импорт,
создание встреч, изменение статуса задач, поиск свободного времени, закрепление
инструментов и сохранение настроек. Регистрация и защита входа восстановлены из
текущего проекта. Оформление приведено к новому макету: пастельное окно,
стеклянная боковая панель с иконками, верхний док на четыре функции,
большое Welcome, поиск с вложением, календарь и четыре портрета помощников.
Сохранены зеркальный Focus и рукописное welcome на экране входа.

Нажмите плюс в доке и выберите инструмент. Его также можно перетащить из боковой
панели. Долгое нажатие на закреплённый инструмент освобождает слот. Настройки
закрепления сохраняются между запусками. Кнопки справа: уведомления, настройки,
выход. Заголовок перетаскивается; края окна позволяют менять его размер.

## Работа с ИИ

В «Настройки → Настроить подключение» выберите Ollama либо облачного провайдера,
модель и при необходимости свой API-ключ. Для внешнего сервиса подтвердите
передачу данных. Ключ можно оставить в памяти либо сохранить под защитой Windows
DPAPI текущей учётной записи. Файл cloud-connection.json находится рядом с базой
в %LOCALAPPDATA%\Focus\FocusDesktop, за пределами проекта и архива.
Ключ не записывается в исходники или QSettings. Проверка OpenAI 12.11.2026
получила HTTP 429 (исчерпан баланс API); содержательные облачные ответы с этим
ключом не подтверждены. Для работы нужен доступный баланс API.

Без модели работают вход, регистрация, задачи, документы, встречи, календарь,
каталог сотрудников, уведомления и проверка локальной защиты. Для ИИ нужен
работающий провайдер. Встречи/задачи сохраняются после явного подтверждения.
Почтовые сообщения остаются в локальном тестовом шлюзе: отправки в реальную почту нет.

## Документы и права

Импортируется один файл, который пользователь явно выбрал. Извлечённый текст
копируется в его личную библиотеку; исходный файл не меняется. TXT, MD, CSV, JSON,
DOCX поддерживаются встроенными средствами. Текстовые PDF требуют доступного
pdftotext или дополнительной библиотеки pypdf. OCR и чтение архивов не реализованы.
Личные папки доступны только владельцу. Каталог сотрудников учитывает роль:
сотрудник видит себя, руководитель — своё подразделение, директор/администратор — компанию.

## Защита и данные

Пароли: PBKDF2-HMAC-SHA256 с солью и 600 000 итерациями; токены в БД — SHA-256.
Сохраняется ограничение неудачных попыток входа и восьмичасовые сессии.
Содержимое документов/объектов, профили, тексты сообщений и предложения операций
шифруются Windows DPAPI с ключами текущей учётной записи Windows. Ключ не входит
в архив и не записывается в исходники. Существующие текстовые поля переводятся
в защищённый вид при запуске; миграция транзакционная, с очисткой журнала SQLite.
Название документа, логин, роль, подразделение и другие метаданные не зашифрованы.
Это шифрование полей, а не всего файла SQLite.

Журнал действий имеет цепочку HMAC с индивидуальным случайным ключом,
защищённым DPAPI. Старые записи с демонстрационным ключом проверяются только
до сохранённой границы миграции. Администратор может просматривать журнал.

Перед обращением к модели маскируются типовые секреты, email, телефоны и реквизиты.
Это не гарантия распознавания всех персональных данных. Presidio подключается,
только если дополнительно установлен с языковой моделью; в архив он не включён.
Подробнее: SECURITY_NOTES.md.

База приложения: %LOCALAPPDATA%\Focus\FocusDesktop\app.sqlite3.
Обновление программы не удаляет пользовательские данные. Перед обновлением
закройте старые копии Focus. После включения DPAPI простого переноса базы в другую
учётную запись Windows недостаточно: там нужны соответствующие ключи/профиль.
В ZIP включена только программа и исходники, личной базы и API-ключей в нём нет.

## Проверки

Протоколы находятся в test-output/final-*.txt. Использованы отдельные временные
базы, реальные облачные сообщения и письма не отправлялись. Сборка проверена на
Windows с Qt 6.12.0 / MinGW / Ninja. Часть проверок требует разрешения на localhost.

## Многостраничный прототип

Доступны поручения (доска / Гант), совещания, почта, календарь, документы,
база знаний, пользователи, аналитика, чат, настройки и аудит. Рабочие записи
проверяются серверными правами. Вымышленные карточки доски и почта обозначены
как демонстрационные. Исторический график иллюстративный; PDF и XLSX
экспортируются в настоящие файлы. Перетаскивание карточек меняет статус
демо-поручения или предлагает подтверждение для рабочего поручения.

Микрофон записывает локальный файл; кнопка «Расшифровать» отправляет выбранную
запись OpenAI после разрешения внешнего подключения. Требуются микрофон,
доступ к API и баланс. Онлайн-текст с демонстрационной встречи — имитация,
она явно подписана в интерфейсе; Realtime-поток не подключён.

ИИ формирует черновики сводок, ответов, рисков и рекомендаций. Почта остаётся
локальным тестовым шлюзом с подтверждением отправки. Календарь локальный;
рекомендации ИИ применяются пользователем. Корпоративные Gmail/Exchange,
SSO и настоящая система лицензирования не подключены.
