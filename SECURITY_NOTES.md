# Границы локальной защиты Focus

Приложение предназначено для локального Windows-компьютера. Сервер слушает
127.0.0.1 на случайном порту и требует случайный ключ текущего процесса Qt.
Права проверяются на сервере отдельно от выбора персонажа и оформления.

## Реализовано

- PBKDF2-HMAC-SHA256 с солью и 600 000 итерациями для паролей; хеши токенов.
- Ограничение ошибок входа, контроль срока сессий, роль сотрудника при регистрации.
- Объектные права и личные папки, подтверждение операций, HMAC-цепочка аудита.
- Индивидуальный случайный ключ аудита хранится в БД только под защитой DPAPI.
- Windows DPAPI защищает objects.data, users.profile, proposals.payload/result,
  messages.body и workspace_state.payload. Ключи текущей учётной записи, без CRYPTPROTECT_LOCAL_MACHINE.
- Миграция прежних незашифрованных полей выполняется транзакционно до запуска HTTP.
- При повреждении шифротекста/отсутствии ключей данные не заменяются пустыми.
- Маскирование типовых секретов и реквизитов перед вызовом провайдера, блокировка
  вызова при ошибке границы приватности. Presidio — необязательное дополнение.

## Ограничения

SQLite целиком не зашифрована: имена, заголовки, роли, пути разрешённых файлов,
метаданные и записи аудита доступны как метаданные. DPAPI не защищает от процесса,
который уже действует с правами текущего пользователя Windows. Данные и обычный
поиск доступны приложению в расшифрованном виде в оперативной памяти.
Перенос/восстановление личной БД между учётными записями и ротация ключей требуют
отдельной процедуры; архив приложения не является резервной копией данных.

Регулярные выражения не дают полной DLP-защиты и могут пропускать имена/адреса
либо маскировать лишнее. Не отправляйте модели сведения, которые нельзя раскрывать
выбранному провайдеру. Промпты не являются границей разрешений: действия по-прежнему
проверяет сервер, модель не получает прямого доступа к SQL или файловой системе.

TLS корпоративного сервера, KMS, SQLCipher, корпоративная почта, полноценное
управление организацией и внешняя оценка безопасности в эту сборку не включены.
Демо-аккаунты нужны для демонстрации; это не аттестация промышленной системы.

Сохранённый API-ключ защищается DPAPI в cloud-connection.json вне проекта.
При переносе ZIP он не переносится. Записи микрофона в папке recordings,
исходные выбранные файлы и экспортированные PDF/XLSX являются обычными файлами;
шифрование текстовых полей базы не распространяется на эти файлы.

API DPAPI: https://learn.microsoft.com/windows/win32/api/dpapi/nf-dpapi-cryptprotectdata
