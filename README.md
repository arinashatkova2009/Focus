# Focus — корпоративный ИИ-ассистент

Настольный интерактивный прототип на **Qt 6 / QML / C++** с локальным Python-сервером. Светлая стеклянная тема, зеркальные кнопки, исходные Eva, Leo, Nick и Robby.

## Открыть в Qt Creator

1. Скачайте репозиторий через **Code → Download ZIP** и полностью распакуйте его либо выполните `git clone https://github.com/arinashatkova2009/Focus.git`.
2. В Qt Creator выберите **Файл → Открыть файл или проект** и откройте **`CMakeLists.txt` в корне**.
3. Выберите комплект **Desktop Qt 6.12.0 MinGW 64-bit** (проверенная конфигурация Windows).
4. Нажмите **Настроить проект**, затем **Ctrl+R**.

Нужны модули Qt Quick, Quick Controls 2, Network, Multimedia, Shader Tools и Quick Dialogs 2. Минимальная версия Qt — 6.10. Встроенный Python для Windows находится в `runtime/python`; отдельно устанавливать Python не требуется. Готовые исполняемые файлы и каталоги сборки не хранятся в Git — Qt Creator создаёт их при сборке.

Первый экран всегда **Welcome → вход / регистрация → главная**. Демо-вход: **arina / 1234**. Новая регистрация создаёт сотрудника без повышенных прав.

## Возможности

- Главная страница, календарь, закрепляемые инструменты, панель агентов и большой чат.
- Поручения: доска, перетаскивание, фильтры и демонстрационное представление Ганта.
- Совещания: встречи, загрузка записей, запись микрофона, расшифровка через OpenAI и черновики сводок.
- Почта: вымышленный входящий ящик, варианты ответа, сохранение в локальный тестовый шлюз после подтверждения.
- Локальное планирование, документы, согласование, история решений, поиск по корпоративным источникам.
- Пользователи и роли, аналитика с экспортом PDF/XLSX, настройки и журнал аудита.
- Облачные адаптеры OpenAI, Anthropic, Gemini и локальная Ollama. Для внешнего сервиса нужны собственный ключ, доступный баланс API и согласие на передачу данных.

## Данные и ограничения

**API-ключей и личной базы в репозитории нет.** Подключение настраивается в приложении. Сохранённый ключ и содержимое полей базы защищаются Windows DPAPI для текущей учётной записи. Метаданные SQLite и обычные файлы записей/экспорта не зашифрованы этим механизмом.

Это интерактивный прототип. Почта работает через тестовый шлюз, календарь локальный, исторический график и онлайн-текст встречи демонстрационные. Потоковая Realtime-транскрибация, корпоративные почтовые системы и SSO не подключены. Запись микрофона и отправка выбранного файла на расшифровку реализованы отдельно от демонстрации потока. Рекомендации ИИ требуют проверки; изменения рабочих объектов подтверждаются пользователем.

Подробнее: [инструкция Qt](README_QT.md), [защита и ограничения](SECURITY_NOTES.md).

## Проверки

На Windows с Qt 6.12.0 MinGW выполнены 44 серверных теста (1 пропущен) и 5 Qt-проверок: вход, регистрация, сохранение, разделы и экспорт. Проверялся также запуск переносимой сборки с очищенным PATH. Аппаратная запись микрофона и содержательные ответы облачной модели не подтверждены этими тестами.

Серверные тесты в PowerShell:

```powershell
Push-Location backend
& ..\runtime\python\python.exe -X utf8 -m unittest discover -v
Pop-Location
```

Qt-проверки: включите CMake-параметр `FOCUS_BUILD_TESTS=ON` и запустите цель `focus_gui_test`. Для работы локального сервера тестам нужен доступ к localhost.
