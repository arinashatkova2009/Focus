# Как устроен прототип

```text
Клиент (будущий HTML/CSS/JS, пока отсутствует)
       │ HTTP JSON на localhost
       ▼
app.py: сессия → роль и проверка доступа → маршрутизация Focus
       │                 │
       │                 ├── SQLite: пользователи, объекты, предложения,
       │                 │   уведомления, тестовая почта, журнал
       │                 └── подтверждение → повторная проверка → сохранение
       │
       └── agents.py: Eva / Leo / Nick / Robby
                │ явно разрешённые источники
                ▼
          providers.py: Ollama / OpenAI / Anthropic
                │
                └── только черновик ответа; вызова инструментов нет
```

AI не работает автономно: после ответа изменения создаются отдельным предложением и требуют подтверждения. Сервер не получает доступ к почте или мессенджеру. Локальные файлы читаются только после подтверждения на конкретный файл; защита реализована в приложении и не заменяет изоляцию операционной системы. Тестовая почта — запись в базе. Календарь — записи SQLite. Проверки полномочий и защита данных являются упрощёнными, поэтому архитектура подходит только для локального прототипирования на синтетических данных.
