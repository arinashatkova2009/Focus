# Герои Focus

Руководитель обращается к Focus. Система пытается определить нужного героя по словам в запросе; при совпадении или непонятной формулировке просит выбрать героя. Пользователь также может указать героя явно. Это простая маршрутизация по ключевым словам, а не полноценный мультиагентный интеллект; взаимодействие между агентами и сквозная координация нескольких героев не реализованы.

| Имя | Персонаж | Область |
|---|---|---|
| Eva | девушка | почта, рабочие переписки, главное, ответы в стиле руководителя |
| Leo | кот | поручения, сроки, статусы, просрочки и разрешённые сведения о рабочем времени |
| Nick | парень | план дня, встречи, повестки, протоколы, поручения и письма по итогам |
| Robby | робот | поиск в доступных документах, сводки, согласования и напоминания |

Описание областей — целевая роль; конкретная готовность функций приведена в `STATUS.md`. Выбор героя не меняет права. При обработке запроса к модели попадают только явно указанные источники, прошедшие серверную проверку прав; файлы компьютера — после отдельного подтверждения чтения. Внешние действия не выполняются моделью напрямую.

## Контракт для будущей анимации

`GET /agents` возвращает стабильные идентификаторы `eva`, `leo`, `nick`, `robby`, название, тип героя, область и список состояний `idle`, `listening`, `thinking`, `speaking`, `success`, `error`. Их можно использовать как основу интерфейса. В этой версии нет 2D/3D-изображений, анимаций, выбора голоса, озвучивания или синхронизации губ. Перед созданием визуала команда утверждает образы, цвета, стили, голоса и сценарии анимации. При выключенном звуке текстовая работа должна оставаться доступной.
